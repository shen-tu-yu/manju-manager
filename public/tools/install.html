漫剧素材助手 · 豆包 Tampermonkey 脚本

在豆包页面加一个素材侧边栏，从你的素材库点一下就把文件送进豆包输入框。
为什么不用「一键安装」？
Tampermonkey 的安装中间页在 https://www.tampermonkey.net 上，它去拉 http://127.0.0.1:8899 会被浏览器当成混合内容拦掉，所以那个页面会卡住不动。手动粘一次就好，十几秒的事。

安装步骤

  1. 点下面的 复制脚本代码 按钮
  2. 点 Edge 工具栏的 Tampermonkey 图标 → 管理面板
  3. 点面板里的 ➕（添加新脚本）
  4. 在编辑区按 Ctrl + A 全选模板内容 → Ctrl + V 粘贴
  5. 按 Ctrl + S 保存
  6. 刷新这个页面（F5） —— 右上角应该出现绿色的 ✅ 脚本已装
    看到了 = 安装成功；没看到 = 安装没生效（多半是粘贴时没覆盖掉 Tampermonkey 的默认模板）
  7. 再去打开 https://www.doubao.com/chat/ —— 右上角出现蓝色的 📁 素材
