# 漫剧素材管理器

一个**零依赖**的本地文件管理 WebUI，专为「用豆包做漫剧、下载一堆图片视频、归类靠拖拽」这个场景做的。

打开浏览器就能**直接浏览文件夹里的所有图片和视频**（不用一张张点开），支持批量改名、拖拽归类、回收站。

---

## 一、怎么启动

**双击 `启动.bat`** —— 先出来一个小菜单（启动器）：

```
  ┌────────────────────────────────────────────────────┐
  │          漫剧素材管理器 · 启动器                   │
  └────────────────────────────────────────────────────┘

    1. 用哪个浏览器打开      系统默认浏览器
    2. 启动后自动打开页面    自动打开（推荐）
    3. 端口                  8899（默认）

   回车 = 就这样启动      输入编号 = 改这一项      r = 恢复默认      q = 退出
```

- **选一次就记住**（存在 `launcher.json`），以后双击直接按回车即可
- 浏览器是**自动扫描**出来的（注册表 `StartMenuInternet` + `App Paths` + 常见路径 + PATH）——
  **装在 D 盘、绿色版、公司定制浏览器都能找到**；实在扫不到的，选「手动输入」粘贴 exe 路径
- 想加新的启动选项（端口、默认目录、开关……）→ 见 `CODE_MAP.md` 2.4，**改一张表就行**

不想用菜单：

```powershell
node launcher.js browser=chrome port=8899   # 按指定选项直接启动（快捷方式可以写这个）
node server.js                              # 完全跳过启动器
```

然后浏览器打开 **http://127.0.0.1:8899**

> 需要 Node.js（你机器上已经有 v22）。除此之外**不需要安装任何东西** —— 不用 npm install，不用 ffmpeg，不用 Python。

**第一次打开**：左侧是空的，点左上角 **＋** 或中间的「添加文件夹」按钮，浏览磁盘选一个文件夹加进来，它就成为你的一个「根目录」

## 二、核心用法

### 看图看视频（不用点开）

- 进文件夹，**图片视频直接铺满右侧**，滚轮往下滚着看
- 视频格子里显示**首帧画面 + 时长**，鼠标移上去**自动播放**，点一下放大继续看，进度条能拖
- 点任意一张 → **全屏灯箱**，`←` `→` 键连续翻页看图，`Esc` 退出
- 右上角切换 **网格 / 大图 / 列表** 三种视图，还能拉滑块调缩略图大小
- 按 **图片 / 视频 / 音频 / 其他** 筛选，按 名称 / 时间 / 大小 排序

### 整理素材

- **左侧目录树 = 你硬盘上的真实文件夹**。你在网页里怎么整理，资源管理器里就变成什么样，不存在"两套结构对不上"

- **拖拽**：选中文件，拖到左侧任意目录节点上，松手即移动

- **批量改名**：选中多个文件按 `F2`，输一个前缀 + 起始序号，一次改完
  
  ```
  1343333430197467.mp4   →   域外恶魔_001.mp4
  13433334548081731.mp4  →   域外恶魔_002.mp4
  13433335059557634.mp4  →   域外恶魔_003.mp4
  ```

- **新建项目**：一次生成整套项目模板目录（`01_场景 / 02_人物 / 03_分镜 / 04_视频片段 / 05_成片`），模板可在设置里改

- **重复检测**：右键空白处 →「检测重复文件」，能揪出重复下载的 `xxx (1).png`

- **回收站**：删除的文件先进回收站，随时能恢复，不会手滑就没了

- **全选整个目录**：`Ctrl+A` 是「全选整个视图」，**不只是屏幕上加载出来的那些**。状态栏会显示
  `已选全部 53 项（含未加载）`，之后批量删除 / 批量改名 / 归类都作用于全部文件
  （点任意一个文件、切目录、改排序筛选，都会自动退出全选）

- **左树右键菜单**：右键左侧任意目录 → 新建子文件夹 / 重命名 / 删除 / 在资源管理器中显示

### 散文件与「散-未归类」虚拟节点

根目录下**没归进任何文件夹**的散文件，不会直接堆在主窗口（否则一屏几十个数字名 mp4 根本没法看），而是收进虚拟节点 **「散-未归类」**：

```
主窗口（根目录）只显示：
  📁 场景          真实文件夹
  📁 人物
  🗂 第1集素材 (8)  虚拟分类
  📦 散-未归类 (45) 虚拟节点
```

**文件本体一个都没动**，虚拟节点只是一层视图过滤。

### 虚拟新建（归类）—— 不会移动文件

在「散-未归类」里选中若干文件 → 点底部 **🗂 虚拟新建** → 起个分类名 → 完成。

- **只记录文件名引用**，文件仍在磁盘原位置，资源管理器里看不出变化
- 也不会在你的素材夹里建任何东西，数据存在程序目录的 `data.db`（SQLite）
- 散文件计数会相应减少，被归进去的文件移到那个虚拟分类下显示
- 把文件从虚拟分类拖回「散-未归类」= 取消归类
- 右键虚拟分类 → 改名 / 删除（**删除只解散分组，文件一个都不会少**）
- 文件若被真实移走、改名或删除，引用会**自动清理**，不留死链

> **虚拟新建 ≠ 新建文件夹。**
> 「虚拟新建」是归类，不动文件；「新建文件夹」才是真的在硬盘上建目录。

### 转实体文件夹（虚拟变实）

虚拟分类是"草稿"，觉得归类得差不多了就让它落地：

- **右键虚拟分类** → 「📦 转为实体文件夹…」，或进入虚拟分类后点底部 **📦 转为实体文件夹**
- 弹窗里选处理方式：

| 方式         | 行为                  | 空间     |
| ---------- | ------------------- | ------ |
| **平移（移动）** | 原文件移进新文件夹，根目录不再保留   | 不占额外空间 |
| **复制**     | 原文件留在根目录，新文件夹里放一份副本 | 占双倍空间  |

- 新文件夹建在根目录下，名字可以改
- **重名绝不覆盖** —— 已有同名文件夹时自动变成「域外恶魔 (1)」
- 平移后分组使命完成，**虚拟分类自动消失**（文件都在实体文件夹里了）
- 复制后原文件还在根目录，所以虚拟分类**保留**（引用依然有效）
- 落地后资源管理器里立刻就能看到

### 上传

把文件从资源管理器**拖进网页窗口**即可上传到当前文件夹；截图可以直接 `Ctrl+V` 粘贴上传（会存成 `image.png`）。

### 新文件自动入库（收件箱）

**Edge 下载完的文件不用你去找** —— 一落到素材夹里就弹一张卡片，问「进哪个库」，还能顺手改名。

- **收哪个目录不用配**：直接读 Edge 的下载设置（`download.default_directory`）。
  你在 Edge 里改了下载位置，网页自动跟着变，**不用改两处**。
  「⚙ 设置」里只做只读展示，可以点「重新读取 Edge 设置」立刻刷新。
- **监听范围**：所有已挂载根目录的**顶层**（不只下载目录）—— 手动往素材夹里拷文件同样会被问到。
  只认文件，新建文件夹不打扰。
- **拖进网页上传的也会问**：从资源管理器拖文件进网页窗口 → 传完同样弹卡片，
  默认落点就是**你拖到的那个文件夹**（不想动就直接点「入库」）。一批文件会等全部传完再逐张问。
- **怎么算下载完**：等文件大小稳定、且同名 `.crdownload` 消失才认，不会拿到半个文件。
- **卡片上有什么**：缩略图预览 · **改名框（主名可改，后缀固定显示、改不丢）** ·
  目标下拉（**按根目录分组、按层级缩进**：根目录 / 各文件夹 / 虚拟分类）· 跳过 / 全部跳过。
  **不改名就按原名入库**到选定位置；重名不覆盖，自动变 `xxx (1)`。
- **⭐ 最近常用**：入库过 **两次以上**的位置会自动置顶到最上面（还标着"用过 N 次"），
  越用越靠前；**最近 10 次入库都没再用它，就自动消失**（"直接进未归类"不算在这 10 次里）。
- **三种策略**（设置里选）：

  | 策略 | 行为 |
  |---|---|
  | 智能（默认） | 文件名"无意义"（纯数字、16 进制串、`img_1234`…）才弹；有意义的静默入库 |
  | 总是询问 | 每个新文件都弹卡片 |
  | 全自动 | 不打扰，直接入库到**上次选的位置**（还没选过就留在原处） |

- **不会自己弹自己**：网页里的上传 / 改名 / 移动 / 从回收站恢复都会登记忽略。
- **想关掉**：设置里取消勾选「监听根目录里的新文件」。

> 唯一处理不了的情况：Edge 开着「下载前询问每个文件的保存位置」时，你手选的目录网页不知道，
> 收件箱只能看到落在默认下载目录里的文件。建议在 Edge 里关掉那个开关。

### 操作日志

工具栏正中间有个胶囊按钮，实时显示**最近一条操作**，点开是完整历史：

```
23:21:00  📦  复制 1 个文件 → 实体文件夹「第一集素材 (1)」
              虚拟分类「第一集素材」（原文件保留，分组保留）
              · 9月8日.png → 第一集素材 (1)\9月8日.png
```

接入的操作：归类 / 移出归类 / **转实体** / 重命名 / 批量重命名 / 删除 / 恢复 / 彻底删除 / 移动 / 剪切 / 复制 / 上传 / 新建文件夹 / 删除虚拟分类。

- **「转实体」记录最详细** —— 每个文件从哪到哪都留痕，回头能查"刚才那批转哪去了"
- 鼠标悬停在记录上可展开被折叠的详情
- 存在浏览器 localStorage，**刷新页面不丢**，保留最近 300 条
- **只记网页里的操作**，你直接在资源管理器里改文件它不知道
- 不记录文件内容，只有文件名和操作类型；「清空」只是删记录，不动文件

### 📚 技能目录（提示词模板）

做漫剧的提示词模板（比如「分镜模板.md」）可以放在**任何位置** —— 不要求和素材放在一起。

- 左侧栏「**技能（提示词模板）**」→ 右上角 **＋** → 在磁盘上选目录 → **挂载一次就记住**，想换路径随时移除重挂
- 只列 **`.md` / `.txt` / `.markdown`**：yaml / json 这类 AI 网页读不好的文件**不列也不投**
- 点文件名可以**预览内容**；鼠标移到目录上点 **×** 解除挂载（**只解除挂载，里面的文件一个都不动**）
- 这些目录与素材根目录**完全隔离**：不会出现在素材树里、收件箱不会监听它、
  回收站也不会在里面建 `.recycle`
- 目录被移走、盘符变了会在列表里标「⚠️ 目录不存在」，不会静默显示成空

> 这是给「**提示词投放**」模块（开发中）准备的模板库 —— 第一期先把"挂载 + 挑模板 + 预览"做好，
> 后面就是：选 skill + 写剧情 → 投给 DeepSeek 网页版 → 结果自动回来切成条目 → 逐条配图 → 投放豆包。

### ✍️ 提示词工作台（开发中 · 第一期）

写剧情、挑 skill、定每个镜头的秒数，然后一条条排出分镜（每条 = 一段提示词 + 一张配图）。

- 左侧栏底部 **✍️ 提示词工作台** 打开：**放大态**居中大窗编辑，**按 Esc 缩成右下角小框**
- **🧠 生成分镜**：写好剧情 + 勾好 skill → 点它，脚本把「剧情 + skill」投给 **DeepSeek 网页版**并自动发送；
  它写完后 webui **自动取回**（会跳过"思考过程"那一段），按 `###` 切成一条条并**自动填进分镜条目**；
  旁边有「查看」（改完可重填）和「撤销」（回到生成前的条目）
- 标题栏有「**投放到**」下拉：选 🫘 豆包 或 🐋 DeepSeek —— 任务按站点隔离，两边的脚本不会互相抢
- **缩小后照样能从素材管理器拖图片进来**：拖到某一条上就配给那条
- **一条提示词可以配多张图**（人物 + 场景 + 风格…）：拖进来是**追加**，同一张不会重复加，
  每条最多 12 张；鼠标移到缩略图上出现 **×** 可单删
- 拖到空白处 → 自动加到第一条还没配图的条目；**只配图，不移动文件**
- 每条可单独改提示词、上移下移、去掉配图、删除；「＋ 加一条」手动加
- skill 用**树形勾选**（和左侧「技能」分区同一套层级），可多选
- 内容存在 `data.db`，**刷新 / 重启都不丢**
- **📤 投放这一条**：助手脚本会把这个条目的**图一张一张投进豆包**（间隔 0.5 秒，确保人和图不串），
  再投提示词；投完你在工作台看到「✅ 已投放，待发送」
- **「发送」按钮**：确认豆包那边没问题后点它，脚本会去点豆包的发送按钮；
  **豆包是按 Enter 发送的**，所以按钮找不到时会自动改用「在输入框按 Enter」
  （**绝不瞎点坐标** —— 点到"清空/上传"是灾难）
- 每条状态都会显示：排队中… / 正在投图… / ✅ 已投放，待发送 / ✅ 已发送 / ❌ 失败原因
- ⚠️ **投放时让豆包停在「对话 / 生成」页** —— 豆包云盘页、设置页里没有输入框和上传控件，
  脚本不会在那种页面上领任务（以前会被抢走然后报"找不到输入框"，现在不会了）。
  同时开多个对话页时，任务可能投到任意一个能用的页面，建议只留一个
- ⏳ 还没做的：把 DeepSeek 生成的分镜自动取回（读它的「复制」按钮）、按分隔符自动切条目

### 📤 投放素材助手（把素材直接"丢"进豆包 / Pavo）

做漫剧时最大的体力活：从资源管理器拖一个文件 → 切到 AI 站点 → 丢进输入框 → 再切回来。这个功能把它变成**点一下**。

**支持三个平台**：

| 平台 | 地址 | 干什么用 |
|---|---|---|
| 🫘 **豆包** | `doubao.com` | 聊天 / 参考图 / 视频生成 |
| 🐋 **DeepSeek** | `chat.deepseek.com` | 写分镜、改提示词（文本） |
| 🎬 **Pavo** | `app.pavo-ai.work` | AI 视频生成（上传参考图） |

**入口**：左侧栏 → **📤 投放素材助手** —— 面板里**选平台 + 一个「打开」按钮**（脚本一份三个站通用，不用分别装）

面板会**自动检测**你装没装，没装就照 4 步做一遍（约 2 分钟）：

1. 点面板里的 **📋 复制脚本代码**
2. Edge 右上角拼图图标 → **篡改猴**（Tampermonkey）→ 管理面板
3. **➕ 添加新脚本** → 编辑区 `Ctrl+A` **全选** → `Ctrl+V` 粘贴 → `Ctrl+S` 保存
4. 回来点 **🔍 重新检测** → 变成绿色「✅ 已经装好了」

> ⚠️ 第 3 步的 `Ctrl+A` 全选不能省 —— 不覆盖掉篡改猴的默认模板，脚本会静默失效。这是最常见的坑。
>
> 一份脚本**同时支持豆包和 Pavo**，装一次两个站都能用；以后加平台也只是加一行域名。

**装好之后怎么用：**

```
打开豆包 / Pavo → 页面右上角点蓝色「📁 素材」→ 侧边栏滑出
               → 点一下素材，文件就进那个站的输入框了
```

- 面板标题会写明当前在哪个站（`📁 漫剧素材 · Pavo`），一眼看出脚本在哪生效
- 侧边栏里是**缩略图网格** —— `1343333430197467.mp4` 这种名字也能看画面认内容
- **抓标题栏可以拖动整个面板**（挡着提示词就拖走，拖到底部就只占下半屏），**左边缘拖动调宽度**
- 标题栏 **－ / ＋** 调预览图大小，**⌂** 一键复位（回到右上角默认大小）
- 位置和大小都记在浏览器本地：关掉页面再打开，**还在你放的地方**
- 也可以从资源管理器**直接拖文件到侧边栏**，松手即送进输入框
- **只把附件放进输入框，不会自动发送** —— 发送按钮始终由你自己按
- 单文件上限 **200MB**（再大走站点自己的上传更合适）

**原理**：脚本注入页面后，运行时**自己扫描** `input[type=file]`，按 `accept` 匹配文件类型，用 `DataTransfer` 把文件塞进去；塞不进去就退回**模拟拖放**。**不写死任何 class 名**，所以站点改版不容易挂，加新平台也只要加一行域名配置。

**排错**：在对应平台页面按 `F12` → Console，看 `[素材助手]` 开头的输出；侧边栏**底部的诊断条**也会写明"找到几个上传控件 / 用了哪种方式 / 送进去几个"。

**两个版本可选**（二选一，别同时开，否则会在同一页面注入两次）：

| 方式            | 怎么装                                                              | 特点            |
| ------------- | ---------------------------------------------------------------- | ------------- |
| **篡改猴脚本**（推荐） | 面板里的 4 步                                                         | 改一行刷新就生效，调试方便 |
| **Edge 扩展**   | `edge://extensions/` → 开发人员模式 → 加载解压缩的扩展 → 选 `D:\文件管理\extension` | 不依赖篡改猴，注入更稳   |

## 四、性能说明

你豆包出的图单张 **5~7MB**（PNG 无损），几十张就是几百 MB。直接铺原图会把浏览器内存吃爆，所以做了两级处理：

1. **懒加载** —— 只加载当前屏幕附近的图，滚到哪加载哪
2. **缩略图缓存** —— 首次进文件夹时，浏览器把图缩到 480px 存进 IndexedDB，**之后进同一个文件夹秒开**；原图只在你点开大图时才加载

缓存不会自动过期，但图片一旦修改（比如改名、重新生成），缓存 key 里带了修改时间，会自动重新生成。缓存占用可以在**设置**里看到并一键清空。

### 分页

一个文件夹里文件很多时，接口**分页返回**（每页 200 条），前端滚到底自动加载下一页 —— 浏览器不会一次性建几千个卡片节点。

- **文件夹不分页**：它们是导航入口、数量少，永远全给
- **排序和筛选在服务端做**（放在前端的话只会排当前那一页）
- 搜索同样分页，每页 100 条

实测一个 2000 文件的目录：一次全量传输 **148 KB**，分页后 **30 KB（-80%）**。

> 诚实说明：分页解决的是**浏览器端**的卡顿（DOM 节点数 -90%）。
> 服务端仍然要把目录 `stat` 一遍才能算出总数和排序，所以**服务端耗时没明显下降**。
> 要真降下来得给文件元数据做缓存，目前没做。

## 五、安全设计

- **默认只绑 `127.0.0.1`** —— 只有这台电脑能访问，同局域网的其他设备打不开
- **路径越界防护** —— 所有请求都被锁死在已添加的根目录内，`../../` 这类请求一律 403 拒绝，不会因为一个链接就漏了整个盘
- **删除是移动不是抹除** —— 进回收站，可恢复
- **跨域白名单** —— 只有 `doubao.com` 域名能跨域读这个服务（投放素材助手要用），其他网站一律拒绝，不会出现"随便点个网页就能读你硬盘"
- 如果想让手机也能看，用 Navicat 把 `data.db` 里 `settings` 表的 `host` 改成 `0.0.0.0` —— **但那样同网段任何人都能删你的文件，务必先想清楚**

## 八、数据与配置

配置和虚拟分类都存在 **`data.db`（SQLite）**，文件就在程序目录里，**不占 C 盘**。

改配置有两个办法：

1. **网页里改**（推荐）：左侧栏 → **⚙ 设置**
2. **用 Navicat 打开 `data.db`**：新建连接 → 选 SQLite → 指向 `D:\文件管理\data.db`

| 表              | 存什么                              |
| -------------- | -------------------------------- |
| `roots`        | 已挂载的根目录（`id` / `name` / `path`）  |
| `settings`     | `port`、`host`、`title`、项目模板、智能规则、**新文件策略**（`autoPolicy` / `inboxEnabled` / `lastIngestTarget`）等 |
| `vgroups`      | 虚拟分类（id / 名称 / 属于哪个根目录）          |
| `vgroup_files` | 每个虚拟分类引用了哪些文件                    |

**备份**：把 `data.db` 拷走就行（稳妥起见连着 `data.db-wal`、`data.db-shm` 一起）。

> 早期版本的 `config.json` / `vgroups.json` 会在首次启动时自动导入数据库，
> 并改名为 `.bak` 留底 —— 确认没问题后可以删掉。

回收站索引不放数据库，仍然在每个素材目录下的 `.recycle\index.json` ——
它和磁盘上的实体回收站目录一一对应，**跟着文件走才安全**（万一你移动了素材盘，库和实体也不会对不上）。
